# Security Policy

## Supported Versions

Kasper is distributed through Go modules and consumed by tag. Release tags are immutable: a published tag is never moved or re-pointed, so a given version always resolves to the same code. Security fixes are released as a new tagged version. Pin to the latest release to receive them.

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do not open a public issue for a suspected vulnerability.

Preferred: use GitHub's private vulnerability reporting via the repository's `Security` tab -> `Report a vulnerability`.

Alternatively, email `security-oss@vitalvas.com`.

Include enough detail to reproduce: affected version, a description of the issue, and a proof of concept or reproduction steps where possible.

## Response

You will receive an acknowledgement of your report. Once the issue is confirmed, a fix is prepared and released in a new tagged version, and the report is disclosed after the fix is available.
